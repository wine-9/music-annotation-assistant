# Contributing

Contributions are welcome, especially reproducible evaluation cases, bug fixes, provider integrations, and improvements that preserve uncertainty instead of forcing labels.

## Development

```bash
make setup
make test
make lint
```

Do not commit copyrighted test audio, private annotation exports, credentials, downloaded model assets, generated outputs, or datasets whose redistribution terms are unclear.

For model-quality changes, include dataset/license context and reproducible metrics where possible.
